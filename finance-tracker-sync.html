🔄 Set up auto-sync

Connect to Firebase so your data syncs automatically between phone and laptop. Free. One-time setup takes 5 minutes.

1
Go to Firebase console
Open console.firebase.google.com → sign in with Google → click Add project → name it "My Finance" → Continue → Create project
2
Create Realtime Database
In your project → click Build → Realtime Database → Create database → pick any location → select Start in test mode → Enable
3
Get your config
Click the gear ⚙️ → Project settings → scroll down → click </> (web icon) → Register app (any name) → copy the firebaseConfig object shown
4
Paste it below
⚠️ Make sure databaseURL is included — it looks like https://xxx-default-rtdb.firebaseio.com
